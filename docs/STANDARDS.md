## 使用规则

1. 已取得原文的：引用时写“标准号 + 条款/表 + PDF 页码”，数值只从原文或页面图像读取，不凭记忆填写。
2. 未取得原文的：只能写“按 HG/T 20519/20570 公开摘要与行业惯例”，**不得编造条款号或具体数值**；验收记录标注“未逐条对标”。
3. 后续若获得 PDF：替换对应条目并复核已生成成果中引用该标准的内容。
