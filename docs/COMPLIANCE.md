# 标准条款符合性矩阵（`compliance_matrix`）

> 定位：把项目已登记标准的**条款级符合性**做成可核查清单；未取得原文的条款只标“待核对”，不填具体限值。

## 输入

```json
{
  "project": "案例A · 2026赛题 · 苯乙烯清洁生产",
  "unit": "乙苯脱氢与分离单元",
  "project_data": {
    "product_purity": 0.998, "product_eb": 0.0008, "product_polymer": 10,
    "design_pressure_mpa": 0.1, "design_temperature_c": 650,
    "qra_done": false, "relief_set_pressure_mpag": 0.5,
    "hazop_done": true, "pid_done": true, "datasheet_done": true
  },
  "answers": {
    "GB31571-COD": {"status": "待确认", "evidence": "未给出废水源强与处理流程"}
  }
}
```

- `project_data`：有确定判据的条款自动判定（产品指标、GB/T 150 范围、重大危险源临界量、排放限值、完成状态）。
- `answers`：人工判定，可取 `符合 / 不符合 / 待确认 / 待核对`，并附证据。
- `ledger`（可选）：覆盖内置台账，用于其他项目/新版本标准。

## 内置台账（29 条，按项目登记标准）

| 标准 | 条款 | 判据 |
|---|---|---|
| GB/T 3915-2021 | 表1 | 纯度 ≥99.8%、乙苯 ≤0.08%、聚合物 ≤10、过氧化物 ≤50、总醛 ≤100、色度 ≤10、TBC 10~15 |
| GB/T 150.1-2024 | 第1章 | 设计压力 ≤35 MPa、设计温度 −269~900 ℃ |
| GB 36894-2018 | 表2/第4章 | 需 QRA 结论（个人/社会风险） |
| GB 18218-2018 | 第4章/表1 | 氢 5 t、苯乙烯 500 t、苯 50 t 临界量对照 |
| GB 31571-2015 | 表1/表3/表4/表6 | COD、氨氮、乙苯/苯乙烯（水）、NMHC、乙苯/苯乙烯（气） |
| HG/T 20519.1~.6-2009 | 第2~6部分 | **待核对**（未取得全文） |
| HG/T 20570.2-95 | 第1章 | 适用 >0.2 MPa 压力容器（扫描页已核对） |
| 项目要求 | — | HAZOP、P&ID 数据链、设备数据表完成状态 |

## 判定规则

| 判定 | 含义 |
|---|---|
| 符合 | 现有项目数据满足该数值/完成状态；**不代表设计文件已通过专业审核** |
| 不符合 | 现有数据超限 |
| 待确认 | 缺项目数据或需专业/环评/安全评价确认 |
| 待核对 | 未取得标准原文，不填具体限值 |

## 输出

- `标准符合性矩阵.xlsx`：符合性矩阵 / 汇总 / 按标准汇总 / 说明；
- `标准符合性矩阵.docx`：A4 横向表格；
- `标准符合性矩阵.json`：完整台账 + 判定过程。

## 诚实边界

- 仅覆盖本项目登记的标准条款；标准换版须更新台账并重新生成；
- 未取得原文的条款保持“待核对”，不得据本矩阵声称合规；
- 排放、QRA、重大危险源、施工图深度等条款须由环评/安全评价/设计审查确认；
- “符合”不等于验收通过，专业审核状态仍为 `not_reviewed`。
