# 工程化绘图工具：P&ID（A1）与设备图（A3）

> 原则：**Agent/LLM 只产出结构化数据；图框、符号、布线、表格、标注、标题栏全部由确定性渲染器生成**。图可以复算、可校验，不依赖云端。

## 1. `pid` —— A1 规范化 P&ID

输出 **A1 横放（841×594 mm）** 单张图：GB/T 14689 风格图框、分区编号、标题栏、修改栏、图例、说明、设备一览表、仪表与阀门表、管线表。

> 定位：**参照 HG/T 20519 内容深度 + ISA-5.1 符号体系的规范化工程示意图**。标准原文未取得，条款级合规与施工图深度仍待核对，不能直接作为施工图。

```json
{
  "title": "乙苯脱氢制苯乙烯 · 工艺管道及仪表流程图",
  "drawing_number": "PID-2026-101",
  "revision": "B",
  "project": "案例A · 2026赛题",
  "designer": "霍昊塬", "checker": "待校核", "approver": "待审核",
  "date": "2026-10-26",
  "nodes": [
    {"id": "R-101", "kind": "reactor", "label": "脱氢反应器", "x": 560, "y": 300,
     "spec": "DN3000×12000", "material": "Q345R", "agitator": true},
    {"id": "TIC-101", "kind": "instrument", "label": "TIC 温控", "x": 500, "y": 560,
     "type": "DCS", "range": "0~800 ℃", "interlock": "I-1 高温联锁"}
  ],
  "edges": [
    {"source": "R-101", "target": "E-102", "kind": "process",
     "line_no": "PL-104-80-A1A", "medium": "反应产物", "spec": "DN80",
     "piping_class": "A1A", "insulation": "保温", "tracing": "伴热",
     "valves": [{"type": "gate", "tag": "HV-101", "position": 0.55},
                {"type": "check", "tag": "CV-101", "position": 0.35}]},
    {"source": "TIC-101", "target": "R-101", "kind": "interlock", "label": "I-1"}
  ]
}
```

调用：`chem_tool(tool="pid", arguments={...})`；调用前可用 `chem_tool(tool="pid_check", ...)` 做规范自检。

绘制规则：

- **设备符号**：容器/反应器（2:1 椭圆封头、裙座、接管、搅拌器）、塔器（封头、塔板/填料、接管）、卧式换热器（壳体、管束、管箱）、泵（泵体+电机+底座）、储罐（拱顶/锥底）、压缩机。
- **仪表**：ISA-5.1 风格圆泡；现场仪表为空心圆，盘装/DCS 带水平线；功能字母+回路号、量程、联锁标注。
- **阀门**：控制阀（蝶形阀体+执行机构）、手动阀/闸阀/球阀/蝶阀/止回阀/安全阀/爆破片/盲板/过滤器；支持写在工艺边上的 `valves` 列表，自动沿路由放置。
- **管线**：正交路由并绕开设备包围盒；管线上标注 **管线号 + 管径/规格 + 管道等级 + 保温/伴热**；工艺线实线、仪表信号虚线、联锁点划线。
- **表格**：设备一览（位号/名称/规格/材料/数量）、仪表与阀门（位号/说明/类型/量程/联锁）、管线表（管线号/起点/终点/规格/等级/介质/保温）。
- **标题栏/修改栏**：项目、图名、图号、版次、设计/校核/审核/批准、比例、日期、张次；修改栏含版次/日期/说明。
- **图例**：工艺线、信号、联锁、现场/盘装仪表、控制阀、手动阀、止回阀、安全阀、爆破片、盲板。

### 1.1 规范自检（`pid_check`）

除结构规则（位号唯一、端点存在、阀门/仪表连接、管线号格式等）外，新增技术内容警告：

- 工艺管线缺 `spec` / `piping_class` / `medium`；
- 仪表缺 `range`，设备缺 `material`；
- 管道阀缺位号或类型不支持；
- 标题栏缺项目/日期/设计/校核/审核/修改说明。

这些警告是“规范化待补项”，不是自动判定合规；`pid_check` 通过仅代表结构可用。

### 1.2 已知差距（诚实记录）

- 未实现 off-page 接续、管线断线/跳线、管道等级库与材料等级库；
- 设备管口未逐一编号/标注，未出管口表；
- 仪表未区分报警/联锁/控制回路等级，未做接线与端子；
- 线宽/符号比例未按企业标准模板校准；
- 未取得 HG/T 20519 原文，**不能声称条款级合规**，也不能作为施工图。
- **图幅**：A1、不按比例（P&ID 惯例）；标题栏含图名、图号、版本、设计/校核/审核、日期、张次；修改栏。
- **输出**：`P&ID.svg` / `.pdf`（内嵌中文字体）/ `.dxf`（mm 单位、图层分离）/ `.json` / `.dexpi.xml`（子集）。

## 2. `pid_check` —— 规则自检

```json
{"validation": {"passed": false, "blockers": ["FV-101：控制阀没有工艺管线"], "warnings": [], "counts": {...}}}
```

规则：

1. 节点 id 唯一、kind 合法、仪表/阀门位号格式；
2. 边端点存在且不相同；
3. 工艺线不得连仪表；设备必须有工艺线；
4. 控制阀必须同时有信号线和工艺线；
5. 仪表必须至少连接一条线；
6. 管线号不得重复；格式应为 `PL-104-80-A1A` 一类；
7. 控制器（TIC/FIC/PIC/LIC…）应连接到控制阀；设备缺 `spec` 给出警告；
8. 结构性问题为 blocker。

## 3. `pid_data` —— P&ID 工程数据链

从同一 P&ID 模型生成可交付数据表（不重新绘图）：

- **管线表**：管线号、介质、起点/终点、规格、管道等级、长度（若填）、保温；
- **材料表（MTO）**：管道按规格/等级汇总（有长度则按 m，否则按条）、控制阀、仪表、弯头/三通/法兰（拓扑估算并逐项标注“需配管复核”）；
- **仪表索引**：位号、功能、类型、量程、信号类型、连接对象、联锁；
- **I/O 清单**：按位号推断 AI/AO/DI/DO（标注“待自控确认”）、去向、联锁说明；
- **联锁因果表（C&E）**：原因（触发仪表）× 后果（设备/阀），单元格 “X”；
- **调节信号表**：仪表 → 控制阀/设备的调节信号矩阵；
- **输出**：`P&ID数据表.xlsx`（7 表）、`P&ID数据表.docx`、`P&ID数据.json`、5 个 CSV。

调用：`chem_tool(tool="pid_data", arguments={...同一 P&ID 模型...})`  
约束：结构性问题（重复管线号、端点缺失、阀门无工艺线等）直接拒绝；估算项与待定项必须在成果中保留标注。

## 4. `cad_part` —— A3 设备图 + CAD 实体

参数化生成压力容器/塔器/储罐/卧式换热器，输出：

- `设备模型.FCStd`、`设备模型.step`（FreeCAD，含筒体、2:1 椭圆封头、裙座、接管与法兰）；
- `设备图.svg` / `设备图.pdf`（**A3 横放**：立面、总高/切线长/直径尺寸、接管标高、设计数据、接管表、说明、标题栏、比例）；
- `设备设计数据.json`（设计参数、壁厚计算、接管、重量清单）。

### 4.1 机械零件：直齿圆柱齿轮（扩展）

当 `equipment_type="gear"` 时，`cad_part` 生成**标准直齿圆柱齿轮**零件图与实体：

- 参数：`module_mm`、`teeth`、`pressure_angle_deg`（14.5/20/25）、`face_width_mm`、`bore_mm`、`hub_diameter_mm`、`hub_width_mm`、`keyway_width_mm`/`keyway_depth_mm`、`accuracy_grade`、`material`；
- 几何：`d=mz`、`da=m(z+2)`、`df=m(z−2.5)`、`db=d·cosα`；齿廓为渐开线（基圆→齿顶），齿根为简化径向/圆弧过渡；
- 输出：`齿轮图.svg` / `.pdf`（A3：端面齿形 + 侧视轮毂/齿宽、参数表、标题栏）、`齿轮图.dxf`（真实齿廓多段线 + 分度/齿根/基圆 + 键槽）、`齿轮模型.FCStd`/`.step`、`齿轮设计数据.json`；
- 限制：无变位、无螺旋角、无齿根修形/公差/热处理；GB/T 1356 基本齿廓与 GB/T 10095 精度原文未取得，图中标注“待核对”；不替代制造图。

调用示例：

```text
chem_tool(tool="cad_part", arguments={
  "equipment_type": "gear", "tag": "GEAR-001",
  "module_mm": 2, "teeth": 20, "pressure_angle_deg": 20,
  "face_width_mm": 20, "bore_mm": 20,
  "hub_diameter_mm": 40, "hub_width_mm": 30,
  "keyway_width_mm": 6, "keyway_depth_mm": 3.5,
  "accuracy_grade": "8", "material": "45钢"
})
```

壁厚按 **GB/T 150.1-2024 内压简化式** 计算（容器类）：

```
筒体 δ = P·Di / (2[σ]t·φ − P) + C1 + C2
封头 δ = P·Di / (2[σ]t·φ − 0.5P) + C1 + C2
```

输入参数（带默认值）：`design_pressure_mpa`、`design_temperature_c`、`material`、`allowable_stress_mpa`、`joint_efficiency`、`corrosion_allowance_mm`、`mill_tolerance_mm`；壁厚取钢板系列值，重量按 7850 kg/m³ 估算。

## 5. 诚实边界

- P&ID 是**规则生成的示意工程图**：不按比例，符号为简化 ISA 风格，未按 HG/T 20519 逐条对标，不能直接作为施工图；DEXPI 文件是**子集**，非认证 DEXPI 2.0。
- 设备图为**参数化外形图**：不含焊缝详图、开孔补强计算、制造公差、保温/内件/平台；实体未抽壳，壁厚以设计数据为准。
- 齿轮图为**机械零件示意/预演图**：渐开线齿廓按几何公式生成，但齿根过渡、公差、材料热处理与检验要求未包含；GB/T 1356/10095 原文未取得，相关标注“待核对”，不替代制造图与齿轮专业校核。
- 高温（>400 ℃）或外压/真空工况下，简化式未计蠕变/持久强度/外压稳定性，须另行校核。
- 所有图都需**设计与校核签字**；工具不替代专业审核。
