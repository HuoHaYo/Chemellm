# 化工工程平台评价协议

目标修订：2026-10-21。当前第一验收是平台实际调用DeepSeek，从一次完整用户任务输入自主交付赛题所需全套正确、可编辑、可运行文件，按[ENGINEERING_ACCEPTANCE.md](ENGINEERING_ACCEPTANCE.md)逐项判断。用户输入至整包产出允许内部多次模型与工具交互；正常运行不得依赖用户逐项指挥、点继续或人工补件。赛题用于检验通用工程平台能力，后续换体系和任务检查迁移。

已有证据截至2026-10-20：NIST回归、Cantera资格、完整203项Python回归、研究任务Web及两次显式任务SIGKILL；另有DeepSeek基础3项交互及两条真实模型批次SIGKILL恢复。前者恢复无LLM，后两条有真实LLM，范围不能混同。这些是组件/公开开发资格，均不等于一轮全套工程交付；详细记录见VALIDATION.md和LINUX_VALIDATION.md。

## 当前验收优先级

先对整包检查原题覆盖、设计依据、数值/工程正确性、跨文件一致性、原生文件运行、编辑/复算及格式呈现。逐项缺失或错误直接驱动平台补齐；保存完整输入、源码/模型/工具版本与轨迹、最终文件和判据。整包失败或人工补件不得用局部成功率抵消，也不能用Codex在平台外制作的文件冒充平台结果。关键工程依据与校核随开发完成；专业审核状态如实记录。

以下多类别评价、消融和用户研究是后续通用能力评价方案，不是当前第一关的前置交付。其规模可按工程覆盖需求调整，不得因追求评测数量推迟完整工程能力建设。

## 层级

1. 实现：代码、界面和接口存在。
2. 实测：实际运行，有输入/输出/环境证据；mock另标。
3. 独立校核：以外部参考、明确容差和适用范围检查；数值算法认证与物理模型验证分开。
4. 人工审核：有可识别审核者、审核对象版本、说明和时间；生成文件或模型自评不升级审核状态。

## 评价集

后续通用能力评价可采用60任务参考规模，按计算20、文献15、实验10、图纸10、长任务5分配，保留评价可参考20项；这是后续建议，非当前第一关硬性前置条件，也非已有成绩。任务按工程师常见工作和迁移需求选择，覆盖多种体系，不能围绕固定苯乙烯答案设计。

每项需保存ID、研究场景、输入/来源哈希、允许工具/资料、任务版本、参考和定位、评判程序或专家量规、容差、严重错误条件、开发/保留划分及审核状态。冻结后变更另开版本。

同一数据、近重复问题或派生任务必须放在同一划分，避免泄漏。保留参考与解答不进入模型上下文或开发调参。已检查或据其修复的案例转开发集，另建新保留样本。NIST Misra1a、BoxBOD和DanWood全部归公开开发资格案例，不宣称盲测。

Cantera的WGS三温度NIST-Shomate对照和四类构造一级反应解析解也属于公开开发资格，不能计作LLM保留集、真实动力学实验或乙苯流程独立基准。NASA与NIST可能共用原始热化学数据；原生/源码包同引擎复算另标为可复现性证据。

## 各类证据

| 类别 | 必须检查 |
|---|---|
| 计算 | 数值和单位、物性/动力学方法适用、数据参数出处、守恒与独立参考偏差；每题按参考精度预先设容差 |
| 文献 | DOI及题名真实、关键论断有全文原句/表格/页码、检索边界与日期、矛盾证据处理、无全文时不编造 |
| 实验 | 数据完整性、单位、模型及误差假设、参数和区间、残差/失拟、独立预测；不只看R² |
| 图纸 | 设备/物流/连接/位号与源图对应；扫描识读另测；图纸与计算数据一致；不将概念草图当合规工程图 |
| 长任务 | 必需项覆盖、工具失败修复、必要追问、参数变更重算、取消与恢复、预算及终止；不能用一句完成声明评分 |

## 模型基线和视觉路由

正式接入模型至少达到deepseek-flash水平，当前以实际可用的 `deepseek-flash` 作为最低对照基线。候选模型按相同任务版本、资料、工具和预算验证专业正确性、引用、工具使用与长任务表现；阈值在评价前登记，不能仅凭名称、参数量或宣传认定达标。快档也遵守该下限；相同映射应如实显示，不静默降级。弱模型可在隔离试验中作对照，不作为正式默认。

先以实际请求确认图像输入、图片格式/大小、工具调用和思考参数支持，再评任务质量。目前云端证据只验证deepseek-flash的文本及工具调用，尚未验证视觉输入。传统RapidOCR/ONNX不再作为识别路线。AI视觉接口未资格化前，扫描件原生文本为空时明确报缺，不把mock或历史OCR转录记为模型看过原图。

在冻结的扫描页、表格、公式和专业图纸样本上，对配置AI视觉模型做字符、关键数值/单位、公式符号、表格单元格、位号/连接识别、失败/拒答、耗时费用及人工纠错评价；不能用平均分掩盖关键数字或连接错误。模型转录必须标为未核验并保留原图、模型ID及哈希。对路线选择有影响的样本属于开发集，后续以新保留样本验收。

原生文本PDF和矢量文件优先直接解析；AI视觉模型未资格化或拒绝图像输入时不静默换成其他OCR。冲突转录保留来源并要求核对。路由增益通过正确率、调用量和复核成本评价；模型视觉输出不免除确定性计算、科学来源核查和版本记录。

## 对照与报告

对照通用模型、检索增强、工具增强；有合理数据和剩余错误时才加微调分支。固定基础模型或披露差异，匹配任务输入、可用资料和预算；工具增强应计入工具与检索耗时。记录模型ID/版本、实际能力、运行参数、日期、随机性、token/费用或本地资源、工具轨迹和人工复核耗时。

每类分别报告通过率、覆盖、拒答/缺失、引用正确率、复算率、严重错误及修复率；失败和拒答留在分母，正确识别不适用另报。速度报告分位数并区分首调用/热启动；没有实际账单/用量时费用留空。不能以一个总分掩盖某类关键错误。

在保留评测前声明发布门槛和统计比较方法，不能看到成绩后修改门槛。参考有争议的任务先复核，不由被测模型裁决。没有独立参考或必要凭据的项保留待验证状态。
