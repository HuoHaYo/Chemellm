# 反应器与含氢冷凝模型

模型代码：app/hydrogen.py、app/frontend_process.py。适用范围：研究筛选，非工程验证模型。

## 数据出处

2026-10-19实际读取 [Sander 氢气条目](https://henrys-law.org/henry/casrn/1333-74-0)。汇编为 *Compilation of Henry’s law constants (version 5.0.0) for water as solvent*，Sander (2023)，DOI [10.5194/acp-23-10901-2023](https://doi.org/10.5194/acp-23-10901-2023)。

选用首条文献评述数据：Hscp(298.15 K)=7.8×10⁻⁶ mol/(m³ Pa)，局部温度系数 dln(Hscp)/d(1/T)=530 K。该行所引文献为 Fernández-Prini、Alvarez、Harvey (2003)，DOI [10.1063/1.1564818](https://doi.org/10.1063/1.1564818)。本项目读取的是汇编条目，没有重新取得并拟合该原始论文数据；局部 van't Hoff 温度式不能代替其完整温度关联式。

本地原始网页为 data/henry-hydrogen-alt.html，35650字节，SHA256：13d930d261ef9058ae3bc1fca3174603309c8162aeb6e7a6b727e6fd424a687f。原始网页保存在研究数据目录，不分发为数据库镜像。

另读取NIST WebBook的H2水溶解度页面，含0.00078 mol/(kg bar)条目，但其页面明确显示部分引用缺失。因此当前实现采用来源更清楚的Sander 2023条目。最初访问旧的Mainz域名时发生证书过期，未关闭TLS验证；后使用当前henrys-law.org站点。

## 单位与有机溶剂

Hscp = cH2 / pH2。换为 Hpx = pH2 / xH2：Hpx = ρ水,molar / Hscp。摩尔密度来自CoolProp纯水（100 kPa）；没有额外乘RT。310 K时约7.56645×10⁹ Pa。

乙苯、苯乙烯中的H2常数缺少经本项目核对的实测数据，使用Peng–Robinson、kij=0、100 kPa下的液相无限稀释预测：Hpx = lim(xH2→0) φH2,L P。对10⁻⁹与10⁻¹⁰两种稀释浓度核对极限。310 K预测约1.57496×10⁸和1.85387×10⁸ Pa。这些数值是预测，不能表述为实测或专业软件基准。

organic_henry_multiplier仅用于改变两种有机溶剂预测值的敏感性。0.5/1/2倍率不表示统计置信区间。水与有机物溶剂采用Dortmund UNIFAC version 1 / DOUFIP2016，也尚缺该体系VLE/LLE实验校验。

## 组成和热力学一致性

组分顺序为水、乙苯、苯乙烯、氢气。令q=xH2，s=1−q，wi=xi/s（溶剂归一化摩尔分数），A=Σwi ln Hi。

液体Gibbs模型由理想混合、s×UNIFAC溶剂过量Gibbs能、溶剂标准态蒸气压及qA项构成。其逸度为：

- 氢气：ln(fH2/P)=ln q + Σwi ln(Hi/P)。
- 溶剂：ln(fi/P)=ln xi + ln γi + ln(Psati/P) + q/s×[ln Hi−Σwi ln Hi]。

溶剂修正来自亨利混合项对组成的导数，不能在任意混合组成下省略，否则不满足Gibbs–Duhem。测试以独立组成微扰检查Σxi dlnfi=0。

所有单元使用组分理想气相生成焓（298.15 K）加气相Cp积分的共同参考。冷凝液焓从相同Gibbs函数对温度的导数得到，包含溶剂冷凝、UNIFAC过量焓和稀溶H2溶解热；温度有限差分检验了热量与化学势导数的一致性。此处数学一致性不证明热负荷已符合实验。

气相为理想气体，忽略Poynting和气相残余焓。实现边界303–313.15 K、50–200 kPa，液体H2≤0.01；至少0.005进料摩尔分数H2。该范围不是实验认证区间。

## 解与校验

尝试VLL、VL水相、VL有机相及稳定全气相分支。求解组成对数、相分率、组分闭合和共存相逸度。再做231点溶剂组成网格和6起点局部TPD搜索；H2浓度方向可解析最小化。稳定性检查可能发现不稳定解，但有限搜索不能证明全局稳定。

联立模型使用400 kmol/h乙苯、蒸汽比8、进料823.15 K、反应873.15 K、转化0.6、100 kPa、冷凝310 K的默认研究假设。出口包括尾气、水相与湿有机相，所有组分均保留。反应供热约11646.002 kW、冷凝移热约76066.943 kW。没有把原料汽化、反应动力学、精馏、循环和全厂负荷包含进来。

后续优先：实测H2有机溶剂及混合溶剂溶解度；独立VLLE和热负荷基准；湿有机相脱气/脱水及多组分塔；闭合循环与产品指标。尾气含芳烃、水相含有机物，需要专门回收/环保设计。
