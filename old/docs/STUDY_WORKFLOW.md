# 研究任务、版本与中断处置

2026-10-20。研究任务用于显式登记的依赖链；执行结束仍需科学或工程审核。

## 日常操作

1. 选择项目，打开“研究任务”。登记研究参数，填写数值、单位、数据类别、适用条件和来源；实验/预测/文献参数必须有来源。
2. 登记任务，选择工具并填写输入。在“参数与上游结果”中，将输入字段连接至研究参数或前序任务。例如：`value`连接压力参数，后续换算的`value`连接前序结果的`value`字段，报告的`body`连接计算结果并选择拼接文字。复杂数组/对象仍可填写JSON；嵌套字段支持`streams/0/supply_C`等路径。
3. 勾选目标任务并执行。系统自动包含全部上游，复用当前有效结果，累计记录工具次数和主动执行时间。取消和时间限制在调用边界检查，已启动工具可能继续返回。
4. 修改参数或任务时保存新版本，关联下游结果及已有审核会过期。旧文件和历史保留；选择报告重算也会先完成必要上游。赛题审核不得将已失效文件重新提升为已通过。

工具页也可把当前输入保存为任务。未显式登记的文件、文献和外部数据依赖目前不会自动推断。

## 服务中断后

正在执行的研究调用重启后标为结果未知。存在未知调用时，新执行和恢复均被拦截，即使已修改任务也不能跳过处置。在“中断调用待核对”中查看实际输入、来源版本和候选计算，核对已有计算及文件后选择：

- 确认重新执行：填写核对者和说明，保存处置后再恢复。旧调用记为`retry_approved`，新调用计入原执行累计次数，不自动清零预算。
- 采用已有记录：选择同项目、同工具、实际输入完全相同且调用后生成的计算。任务版本及依赖必须仍有效；失败/不可用记录不能采用。成功后复用原计算及文件，保留原字节和ID。

处置保留事件、核对者和依据，只确认执行结果，不构成科学审核。候选列表最多20条，包含时间范围内其他计算；服务器会独立检查选定记录的项目、工具、输入与版本。界面处置对话框已实现，端到端浏览器操作仍待验收；HTTP实机路径及拒绝条件已验证。
