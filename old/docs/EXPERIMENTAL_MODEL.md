# 实验表格分析与回归边界

更新：2026-10-20。

## 输入与追溯

CSV为UTF-8，可识别逗号、分号或制表符；XLSX用openpyxl只读、禁用外链保留且不计算公式。首行列名须唯一非空，最多5000行、100列，Office解压总量最多100 MiB。分析保留工作表、原始行号、列名、单位、原文件SHA256与各模型数值记录。

全空行跳过并记录；所选数据列含缺失、非有限值、公式或文本时明确拒绝。没有插值、异常点静默删除或自动单位推断。公开NIST导入仅使用原始文件声明过的单位；未声明的单位沿用原数值尺度，并显式说明其含义。

`dataset_inspect`查看；`analyze_dataset`在当前项目下读取；`fit_data`为独立、可复算的数值工具。编排记录关联原始数据SHA256，每个候选模型的x/y/标准差与输入参数另外记录到`fit_data`。包内复算这些数值记录；文件/图表生成不自动重跑。失败模型逐项显示，不能悄悄从候选集合删除。

## 模型与统计假设

| 模型 | 方程与边界 |
|---|---|
| 线性 | y=a+b x，无非负约束 |
| 一级衰减 | y=a exp(-k x)，a,k≥0，x≥0；不自动定义时间原点 |
| 一级趋近 | y=a[1-exp(-k x)]，a,k≥0，x≥0；经验方程不自动认定吸附/反应机理 |
| 幂律 | y=a[x/(1个声明单位)]^b，a≥0，-50≤b≤50，x>0；单位变化会改变幅值 |
| Arrhenius | y=k_ref exp[-Ea/R(1/T-1/T_ref)]；输入温度转K并拒绝T≤0；T_ref为样本绝对温度的调和平均；k_ref≥0，Ea在±1e6 J/mol数值范围内 |

使用有解析雅可比的SciPy least_squares，按参数尺度求解。一级趋近采用多个自动初值，其他模型使用数据尺度初值，亦可通过fit_data显式给初值。成功收敛不保证全局最优或科学模型正确。

没有sigma列时进行普通最小二乘；提供sigma时最小化Σ[(y-f)/sigma]²。absolute_sigma=false时sigma表示相对权重，协方差乘以残差估计尺度并使用n-p自由度Student t；true时sigma为已知绝对观测标准差，协方差不按残差缩放，区间用正态分位数。

参数协方差与曲线区间来自局部线性传播；假定独立观测、自变量误差可忽略且模型结构适用。秩不足或约束边界解不给区间；参数高相关有提示。残差经观测sigma和适用的残差尺度标准化，未作杠杆值学生化。重复实验可在未加权且有纯误差自由度时提供失拟F检验；其解释同样依赖误差假设。

曲线阴影是模型均值的局部置信区间，不能解释为新观测预测区间。显式范围外预测需allow_extrapolation=true并标注，不计入结构/外推误差。尚未实现bootstrap、轮廓似然、多变量辨识、ODE动力学和正式最优实验设计。

## 模型比较

同一数据、同一误差假设比较高斯似然AIC/AICc；未知残差尺度计入额外一个似然参数。样本不足以定义AICc时改用AIC；完全零残差不伪造有限似然成绩。候选不适用/失败单独列出。信息准则排序不能证明机理、因果、研究新颖性或外部预测有效。
