# 四元循环流程研究模型

该模型在反应—冷凝—四元湿塔单程计算基础上，把塔顶有机馏出按给定比例排放，其余水/乙苯/苯乙烯/H2全部送回反应进料。不假设回流为纯乙苯。单反应、UNIFAC/Henry物性与单液热塔板仍缺该体系实验和独立模拟器基准；数学闭合不能作为赛题工程验收。

## 单元与边界

1. 新鲜乙苯为指定温度的液体；外部水蒸汽在反应进料温度下作为气体供给。蒸汽比定义为反应器入口总水/总乙苯，补充蒸汽量扣除循环水。
2. 循环液从塔压提升到反应压力。轴功按 `W = n V ΔP / η` 计算，V为输入的平均液体摩尔体积；默认0.12 m³/kmol、效率0.7都是待校核假设。轴功进入实际焓流，不通过无功压力跳变隐去。未求泵出口温升、NPSH、厂家性能曲线或机械选型。
3. 预热/汽化负荷为反应器实际气相进料焓减新鲜液体、外部蒸汽、冷循环液焓及泵功。共同参考为组分298.15 K理想气体生成焓与Cp积分，液相焓从同一Gibbs模型温度导数得到。纯乙苯液体采用 `hL=hG−RT² dlnPsat/dT`。忽略液体压力焓变化；泵功按单独机械能近似处理。
4. 反应器保留进料SM和H2。指定转化率作用于总进料乙苯，单反应为EB⇌SM+H2。理想平衡用 `(nSM+ξ)(nH2+ξ)P = Kp P°(nEB−ξ)(ntotal+ξ)`，根允许为负。指定正向反应超过混合进料平衡上限即拒绝继续。
5. 前端冷凝为100 kPa、310 K等研究条件，保留气、水、有机三相；有机相按实际流量与焓降压进入湿塔。塔顶有机液内回流与对外有机馏出分别计量；对外馏出再分为循环和排放。
6. 流程外边界包括新鲜乙苯与补充水蒸汽，出口为前端尾气/水相、塔顶尾气/水相、塔底和有机排放。内部反应物流、湿塔进料、塔顶有机馏出及循环不得重复计入整体衡算。

## 循环与求解

求解四维不动点 `r=(1−purge) Dorganic xorganic`，用Anderson加速和上一轮完整湿塔解作为初始化；最多24轮、240秒。每一轮都检查单元守恒、相平衡和有限TPD稳定性。循环闭合指标为 `max |rout−rin|/max(1,|rout|)`，要求小于1e-9；同时检查外边界组分、原子、质量和能量，不能以循环残差单独宣称成功。

湿塔用流入/流出组分流量的对数比构造逐级残差，避免微量水/H2方程因绝对值小而丢失。较多塔板的初始化用理想二元分布提供烃组成初猜，再解水/H2逐级线性衡算；最终仍完整求解四元MESH、VLL塔顶及原关联式。二元初猜不是四元结果。稀疏Newton与回溯线搜索优先，失败时回退带边界的最小二乘；研究示例已覆盖6/12/50级，其他工况不保证收敛。

## 数据与纯度

反应数据及物性范围见 [TECHNICAL_PATH.md](TECHNICAL_PATH.md)、[HYDROGEN_MODEL.md](HYDROGEN_MODEL.md) 和 [WET_COLUMN_MODEL.md](WET_COLUMN_MODEL.md)。前端水中H2用Sander低温参数，湿塔用IAPWS宽温关联式；有机H2仍为PR/kij=0预测，溶剂为Dortmund UNIFAC。两套水中H2模型差异明确保留，连接时不重置上游实际焓。

塔底纯度按全部四组分质量计算：`wSM=nSM MSM / Σni Mi`，与输入目标比较。默认0.998是研究假设，不是经市场调查确认的产品标准，也未包含真实副产物、阻聚剂、水分专项标准等。数值达到该指标只能称达到指定纯度目标，不能称完成产品验收。极微量预测尾数不代表实测精度。
