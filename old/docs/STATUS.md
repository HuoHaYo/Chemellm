# 当前完成度与后续工作

目标修订于2026-10-21；以下实测基线截至2026-10-20。平台目标是胜任化工工程师大部分工作的通用工程平台。**当前第一验收目标是一次完整用户输入后，由平台实际调用DeepSeek自主交付赛题要求的全套正确、可编辑、可运行文件。当前尚未通过。** 赛题是验收工具，研究、测试和恢复能力为工程交付服务。见[平台目标](RESEARCH_PLATFORM_GOAL.md)、[整包判据](ENGINEERING_ACCEPTANCE.md)和[阶段审计](RESEARCH_ACCEPTANCE.md)。

当前建设优先级：统一设计依据及要求/成果清单→完整流程模拟优化→设备、公用工程、安全环保和经济→PFD/P&ID、布置及三维原生文件→DeepSeek自主编排、全套生成及跨文件校核→真实一轮整包验收。模块按依赖推进，既有功能与回归维护；大规模评测、研究消融或微调不作为整包交付的前置阶段。一轮允许内部多次模型/工具交互，正常完成不依赖用户逐项操作、点继续或人工补件。

已有单元研究包括873.15 K乙苯脱氢热力学、50级/20 kPa乙苯-苯乙烯塔，以及水/乙苯/苯乙烯LL/VLL。各工况是独立假设，不能混作同一条闭合流程；没有以删除含水/氢气或完全分离来伪造流程结果。

反应-含氢冷凝前端工具支持四元全组分传递、五条物流、共同焓基准及敏感性研究。水中H2用Sander2023汇编参数，有机溶剂H2是PR无限稀释预测。已通过Gibbs–Duhem、焓导数、相平衡/守恒与分支检查，但尚无实验或独立软件验证。该工具范围到冷凝器，湿塔连接由下述工具提供。说明见 [HYDROGEN_MODEL.md](HYDROGEN_MODEL.md)。

一次通过的反应—冷凝—湿精馏工具传递实际流量和焓、等焓降压、四元MESH热级、VLL塔顶和有机液内回流。输出九条物流；其6级/12级旧研究包已按所附旧源码复算。水中H2宽温参数核对IAPWS原表。12级默认塔底苯乙烯约0.799；改进求解后，50级/R=10单程案例约0.99829摩尔分数。该工具本身无外部乙苯循环，循环由下述工具提供。见 [WET_COLUMN_MODEL.md](WET_COLUMN_MODEL.md)。

四元循环工具将有机馏出的四种组分按给定排放比例返回实际反应进料，包含杂质的平衡抑制、循环泵功和冷料汽化/预热。50级/R=10/1%排放默认案例循环8轮闭合；13条物流、外部组分/原子/质量/共同参考能量检查通过。塔底苯乙烯质量分数约0.999002，达到指定0.998研究目标，但没有按完整产品标准验收。研究报告/PPT/图纸和独立解压复算均已完成；无催化动力学/副反应、实验/独立模拟器基准或设备/全厂工程设计。见 [RECYCLE_MODEL.md](RECYCLE_MODEL.md)。

测试、浏览器及独立复算证据见 [VALIDATION.md](VALIDATION.md)。代码存在、残差合格、文件生成和人工审核是不同层级的证据。

当前限制：单工作台共享口令、单Uvicorn worker、进程内线程队列。研究任务和对话执行器均在重启后拦截未知调用，明确处置后才允许恢复；已确认结果复用、未开始的批次余项继续，详见[对话恢复](AGENT_RECOVERY.md)。时间恢复保守计入停机上界；费用预算、硬性终止、跨进程队列和一般性恰好执行一次语义尚未验收。无模型配置时返回明确错误，不用模板回复冒充模型执行。

实验分析新增独立认证参考：NIST StRD Misra1a（吸附）、BoxBOD（生化耗氧）、DanWood（碳丝灯辐射）。参数、标准差与SSE均通过事先写定的数值容差；三个参考在开发中可见，不作为保留/盲测集或专业机理验证。来源原件、哈希和边界见 [EXPERIMENTAL_MODEL.md](EXPERIMENTAL_MODEL.md)。

湿塔已验证6/12/50级研究示例。旧求解器的50级案例曾超时；现在用逐级微量组分对数衡算、二元分布/稀组分初猜和稀疏Newton后，完整四元方程通过检查。输入级数范围不保证任意工况都收敛；二元初猜不充当四元最终结果。

计算入口串行保护thermo/Chemicals共享惰性初始化，避免并发首调用出现未初始化数据表。数值工具会排队；计算服务拆分和任务限流尚未实现。
